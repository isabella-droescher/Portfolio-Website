# **Portfolio Website**

Responsive Portfolio-Website mit Fokus auf UI, Performance und Mobile UX

## **Überblick**

Entwicklung einer modernen Portfolio-Website zur Präsentation eigener Projekte, Fähigkeiten und UI/UX-Arbeiten mit Fokus auf responsives Design und klare Nutzerführung.


## **Ziel**

Konzeption und Umsetzung eines performanten und responsiven Webauftritts zur strukturierten Darstellung von Projekten und technischen Kompetenzen.


## **Design-Fokus**

Das Portfolio fokussiert sich insbesondere auf:

* klare visuelle Hierarchien
* responsive Mobile-First Gestaltung
* reduzierte und konsistente UI-Strukturen
* performante und übersichtliche Nutzerführung


## **Technologien**

HTML · SCSS · Bootstrap · JavaScript


## **Meine Rolle**

UI/UX Design · Frontend Development · Responsive Design


## **Prozess**

* Konzeption der Seitenstruktur und Navigation
* Entwicklung responsiver Layouts für verschiedene Bildschirmgrößen
* Gestaltung konsistenter UI-Komponenten
* Optimierung von Performance und Nutzerführung


## **Lösung**

* Responsives Portfolio für Desktop und Mobile
* Strukturierte Darstellung von Projekten und Skills
* Konsistentes visuelles Design mit klarer Navigation
* Optimierte Darstellung für unterschiedliche Endgeräte
